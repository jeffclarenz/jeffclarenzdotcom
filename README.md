# jeffclarenz.com

Personal portfolio site for Jeff Clarenz — Engineer · Founder · CTO.

Built with [Astro](https://astro.build). Content managed via [Sanity](https://sanity.io).

## Quick start

```bash
npm install
npm run dev       # http://localhost:4321
```
